# CMA 프로젝트 단기 목표 및 최우선 목표

*최종 업데이트: 2025년 1월 23일*

## 🎯 최우선 목표 (1-2개월)

### 1. 핵심 기능 완성 및 안정화
- **목표**: 기본적인 건설 관리 시스템으로 사용 가능한 상태 달성
- **기간**: 4-6주
- **우선순위**: 최고

#### 1.1 계약 관리 모듈 완성 (2주)
- [ ] 계약 생성/수정/삭제 기능 완성
- [ ] 계약 상태 추적 시스템
- [ ] 계약서 자동 생성 기능
- [ ] 계약 이력 관리
- [ ] 계약 검색 및 필터링

#### 1.2 재무 관리 모듈 완성 (2주)
- [ ] 예산 계획 및 추적
- [ ] 비용 분석 및 보고
- [ ] 수익성 분석
- [ ] 재무 보고서 자동 생성
- [ ] 예산 대비 실적 비교

#### 1.3 노무 관리 모듈 완성 (2주)
- [ ] 인력 배치 및 관리
- [ ] 작업 시간 추적
- [ ] 임금 계산
- [ ] 노무비 분석
- [ ] 인력 스케줄링

### 2. ASCR 모듈 통합 완성 (2주)
- [ ] PDF 텍스트 추출 기능
- [ ] 목차 자동 생성
- [ ] 문서 분할 및 병합
- [ ] 표준품셈 자동 적용
- [ ] 문서 검증 시스템

### 3. 기본 UI/UX 완성 (2주)
- [ ] 메인 대시보드 완성
- [ ] 네비게이션 시스템
- [ ] 반응형 디자인 적용
- [ ] 사용자 피드백 수집 및 반영
