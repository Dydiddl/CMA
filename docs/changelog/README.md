# 변경 로그

*최종 업데이트: 2025-01-23*

이 폴더는 CMA 시스템의 모든 버전별 변경 사항을 기록합니다.

## 📋 버전 관리

### 시맨틱 버저닝 (Semantic Versioning)
- **MAJOR.MINOR.PATCH** 형식 사용
- **MAJOR**: 호환되지 않는 API 변경
- **MINOR**: 호환되는 새로운 기능 추가
- **PATCH**: 호환되는 버그 수정

- [v3.1.0](v3.1.0.md) - 현재 버전

## 🔄 변경 유형

### 기능 추가 (Features)
- 새로운 기능이나 모듈 추가
- 기존 기능의 확장
- 새로운 API 엔드포인트 추가

### 개선 사항 (Improvements)
- 성능 최적화
- 사용자 경험 개선
- 코드 품질 향상
- 문서 개선

### 버그 수정 (Bug Fixes)
- 오류 수정
- 동작 오류 수정
- 보안 취약점 패치

### 변경 사항 (Changes)
- 기존 기능의 변경
- API 변경
- 설정 변경

### 제거 사항 (Removals)
- 더 이상 사용되지 않는 기능 제거
- 지원 중단된 기능 제거

## 📝 변경 로그 작성 규칙

### 작성 형식
```markdown
# vX.Y.Z - YYYY-MM-DD

## 추가된 기능
- 새로운 기능 A
- 새로운 기능 B

## 개선된 사항
- 성능 최적화
- 사용자 경험 개선

## 수정된 버그
- 버그 A 수정
- 버그 B 수정

## 변경된 사항
- API 변경
- 설정 변경

## 제거된 기능
- 더 이상 사용되지 않는 기능
```

### 작성 가이드라인
1. **명확한 설명**: 변경 사항을 명확하고 간결하게 설명
2. **사용자 관점**: 사용자에게 미치는 영향을 중심으로 작성
3. **기술적 세부사항**: 개발자를 위한 기술적 세부사항 포함
4. **호환성 정보**: 기존 기능과의 호환성 정보 제공
5. **마이그레이션 가이드**: 필요한 경우 마이그레이션 방법 제공
