# 개발 가이드

## 1. 개발 환경 설정

### 1.1 하이브리드 아키텍처 전략
- **Python 기반 개발**: 빠른 개발과 유지보수성 우선
- **선택적 네이티브 최적화**: 성능 병목 지점만 네이티브 전환
- **단계적 최적화**: Python 최적화 → 하이브리드 최적화 → 완전 최적화

### 1.2 데이터베이스 전략
- **개발 단계**: 로컬 PostgreSQL 데이터베이스 사용
  - 이유: 비용 절감, 빠른 개발, 안전한 테스트 환경
  - 설정: PostgreSQL 14 버전 사용
  - 데이터베이스명: construction_management

- **테스트/스테이징 단계**: Supabase 사용
  - 이유: 실제 환경과 동일한 조건에서 테스트
  - 실제 사용량 파악 가능
  - Supabase의 특별 기능 테스트

- **프로덕션 단계**: Supabase 사용
  - 이유: 클라우드 기반 안정성
  - 다중 사용자 접근 지원
  - 확장성 확보

### 1.3 기술 스택 (2025년 1월 기준)
- **프론트엔드**: React 18.2.0 + TypeScript 5.8.3 + Vite 4.5.14
- **UI 라이브러리**: Mantine 8.1.0 + Material-UI 5.17.1
- **데스크톱 앱**: Tauri 2.5.0
- **백엔드**: Python 3.12+ + FastAPI 0.115.12
- **데이터베이스**: 
  - 개발: PostgreSQL (로컬)
  - 프로덕션: Supabase (PostgreSQL 기반)
- **성능 최적화**: Redis, Celery, 멀티프로세싱

## 2. 개발 프로세스

### 2.1 가상환경 관리 (MANDATORY)
```bash
# 백엔드 개발 시
cd backend
source venv/bin/activate  # Linux/Mac
# 또는 venv\Scripts\activate  # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload

# 데스크톱 앱 개발 시 (새 터미널)
cd desktop
source venv/bin/activate  # Linux/Mac
# 또는 venv\Scripts\activate  # Windows
pip install -r requirements.txt
python main.py
```

### 2.2 로컬 개발 환경 설정

2. 로컬 데이터베이스 생성
3. 백엔드 환경 변수 설정
4. 프론트엔드 개발 서버 실행
5. 가상환경 활성화 확인

### 2.3 데이터베이스 마이그레이션

## 3. 코드 구조

### 3.1 백엔드 구조
```
backend/
├── app/
│   ├── api/          # API 엔드포인트
│   ├── core/         # 핵심 설정
│   ├── services/     # 비즈니스 로직
│   ├── models/       # 데이터 모델
│   └── utils/        # 유틸리티 함수
├── tests/            # 테스트 코드
├── venv/             # 가상환경
└── main.py          # 애플리케이션 진입점
```

### 3.2 프론트엔드 구조
```
frontend/
├── src/
│   ├── components/   # UI 컴포넌트
│   ├── pages/        # 페이지 컴포넌트
│   ├── services/     # API 서비스
│   ├── types/        # TypeScript 타입 정의
│   └── utils/        # 유틸리티 함수
├── public/          # 정적 파일
└── package.json     # 의존성 관리
```

### 3.3 데스크톱 앱 구조
```
desktop/
├── src/
│   ├── ui/          # PySide6 UI 컴포넌트
│   ├── services/    # 비즈니스 로직
│   ├── models/      # 데이터 모델
│   └── utils/       # 유틸리티 함수
├── venv/            # 가상환경
└── main.py         # 애플리케이션 진입점
```
