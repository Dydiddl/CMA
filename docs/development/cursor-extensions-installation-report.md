## 🎯 설치된 확장 프로그램의 주요 기능

### 1. Python 개발 환경
- **Black 포맷터**: 자동 코드 포맷팅
- **isort**: import 문 자동 정렬
- **flake8**: 코드 품질 검사
- **디버깅**: 통합 디버거 지원

### 2. TypeScript/React 개발 환경
- **TypeScript Next**: 최신 TypeScript 지원
- **Prettier**: 코드 포맷팅
- **ESLint**: 코드 품질 검사
- **자동 태그**: HTML/JSX 태그 자동 완성

### 3. Git 및 버전 관리
- **GitLens**: 고급 Git 기능
- **Git Graph**: 시각적 Git 히스토리
- **Docker**: 컨테이너 관리

### 4. 문서 처리
- **Markdown All in One**: 완전한 Markdown 지원
- **PDF 뷰어**: PDF 파일 직접 보기

```bash

# .vscode/launch.json - 디버깅 설정
# .vscode/extensions.json - 권장 확장 프로그램
```

### 2. Cursor 재시작
```bash

```

- Python 인터프리터 경로 확인
- TypeScript 설정 확인
- Git 설정 확인

### 4. 테스트 실행
```bash

cd backend && python -m pytest
```
