## 🎯 사용자 유형별 가이드

### 관리자
- 시스템 설정 및 사용자 관리
- 권한 설정 및 보안 관리
- 전체 프로젝트 모니터링

### 프로젝트 매니저
- 프로젝트 생성 및 관리
- 계약 및 재무 관리
- 팀원 및 작업자 관리

### 일반 사용자
- 기본 기능 사용법
- 데이터 입력 및 조회
- 보고서 생성 및 출력

## 📋 문서 작성 규칙

1. **단계별 설명**: 복잡한 기능은 단계별로 설명
2. **스크린샷 포함**: 중요한 화면은 스크린샷 추가
3. **예시 제공**: 실제 사용 예시 포함
4. **문제 해결**: 자주 발생하는 문제와 해결방법 포함

## 🔄 문서 업데이트

- 새로운 기능 추가 시 관련 가이드 작성
- 사용자 피드백 반영
- 정기적인 내용 검토 및 업데이트
