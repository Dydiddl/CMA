# 🏗️ ASCR 시스템 아키텍처

## 📋 **프로그램 최종 목표**
**엑셀 내역서 작성 자동화 시스템**

건설업계 표준가격표 PDF를 자동으로 처리하여 엑셀 내역서 작성에 필요한 데이터를 추출하고, 자동으로 내역서와 총공사총괄표를 생성하는 시스템

## 🔄 **전체 시스템 흐름**

```
1. PDF 다운로드 → 2. 목차 추출 → 3. 구조 분석 → 4. PDF 분할 → 5. 데이터 추출 → 6. 엑셀 연계
```

### **Phase 1: PDF 전처리 (현재 단계) ✅**
- [x] PDF 자동 다운로드
- [x] 목차 PDF 추출 (`index.pdf`)
- [x] 목차 구조 분석 (부문/장 분류)
- [x] PDF 분할 (부문별 폴더 + 장별 PDF)

### **Phase 2: 데이터 추출 (다음 단계) 🔄**
- [ ] 텍스트 추출 및 구조화
- [ ] 공종별, 품목별 데이터 정리
- [ ] 룩업테이블 생성
- [ ] 데이터 검증 및 품질 관리

### **Phase 3: 엑셀 연계 (최종 단계) 📊**
- [ ] 엑셀 템플릿 연계
- [ ] 자동 계산 엔진
- [ ] 내역서 자동 생성
- [ ] 총공사총괄표 생성

## 🛠️ **현재 구현된 기능**

### **1. PDF 다운로드 시스템**
```python
scripts/download_standard_price_list.py
```
- 건설업계 표준가격표 PDF 자동 다운로드
- 목차 PDF 추출 (`index.pdf`)
- PDF 구조 검증

### **2. PDF 처리 시스템**
```python
scripts/extract_split_3_49_unified.py  # 텍스트 추출 + 목차 분석
scripts/pdf_split_by_chapters.py       # 장별 PDF 분할
scripts/pdf_split_by_sections.py       # 부문별 PDF 분할
scripts/analyze_chapters.py            # 장 정보 분석
scripts/test_validation_rules.py       # 검증 규칙 테스트
```

### **3. 메인 컨트롤 시스템**
```python
main.py
```
- 통합 메뉴 시스템
- 자동화 워크플로우
- 에러 처리 및 피드백

## 🎯 **개발 로드맵**

1. **텍스트 구조화 엔진**
   - 각 장별 상세 내용 추출

   - 가격 정보 추출 및 정규화

   - SQLite 또는 JSON 기반 데이터 저장

   - 데이터 무결성 검증

3. **룩업테이블 생성기**
   - 엑셀 연계용 CSV/Excel 파일 생성
   - 데이터 매핑 및 변환
   - 품질 검증 리포트

### **Phase 2B: 데이터 검증 시스템 (1주)**
1. **자동 검증 엔진**
   - 데이터 완성도 검사
   - 가격 범위 검증
   - 중복 데이터 확인

2. **품질 관리 시스템**
   - 오류 리포트 생성
   - 수정 제안 기능
   - 데이터 백업 및 복구

### **Phase 3A: 엑셀 연계 시스템 (2-3주)**
1. **엑셀 템플릿 엔진**
   - 내역서 양식 템플릿
   - 총공사총괄표 템플릿
   - 사용자 정의 템플릿 지원

2. **자동 계산 엔진**
   - 수량 × 단가 계산
   - 할증/할인 적용
   - 세금 계산

3. **데이터 매핑 시스템**
   - 품목 코드 매핑
   - 단위 변환
   - 통화 변환

### **Phase 3B: 사용자 인터페이스 (1-2주)**

2. **배치 처리 시스템**

   - 결과 통합

## 🔧 **기술 스택**

### **현재 사용 중**
- **Python 3.8+**: 메인 프로그래밍 언어
- **PyPDF2**: PDF 처리
- **pandas**: 데이터 처리
- **openpyxl**: Excel 파일 처리
- **requests**: HTTP 요청

### **추가 예정**
- **SQLite**: 데이터베이스
- **tkinter/PyQt**: GUI 인터페이스
- **matplotlib**: 차트 생성
- **jinja2**: 템플릿 엔진

## 📊 **데이터 구조 설계**

### **목차 구조 (JSON)**
```json
{
  "sections": [
    {
      "name": "공통부문",
      "chapters": [
        {
          "name": "조경공사",
          "start_page": 100,
          "end_page": 150,
          "items": [
            {
              "code": "A001",
              "name": "관목식재",
              "unit": "본",
              "price": 5000
            }
          ]
        }
      ]
    }
  ]
}
```

### **룩업테이블 구조 (CSV)**
```csv
품목코드,품목명,단위,단가,부문,장,페이지
A001,관목식재,본,5000,공통부문,조경공사,105
A002,교목식재,본,15000,공통부문,조경공사,110
```
