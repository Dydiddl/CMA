# 🏗 ASCR 프로젝트 개발 명세서 (건설공사 내역서 자동화 시스템)

## 1. 프로젝트 개요

### 1.1. 개발 배경 및 필요성
- 건설공사 설계 시 반복적으로 유사한 구조의 문서를 수작업으로 작성하게 됨.
- 매년 변경되는 **표준품셈**, **노임단가**, **조달청 제비율표** 등을 반영해야 하며, 이 과정이 반복적이고 비효율적임.
- 따라서 **문서 자동화 시스템**을 구축하여 업무 강도를 줄이고, 실수를 방지하며, 최신 정보를 반영하는 체계를 구축하고자 함.

### 1.2. 개발 목적
- 반복되는 공사 문서 작성의 자동화
- 최신 공공 데이터(표준품셈, 노임단가 등)의 반영 자동화
- 수동과 자동의 적절한 혼합(반자동) 시스템 구축 → 점진적 완전 자동화로 확장 가능

## 2. 개발 방향 및 전략

### 2.1. 개발 전략
- **우선 완성 가능한 기능부터 구축**하여 전체 흐름이 가능한 수준의 MVP(최소 기능 제품) 개발
- 이후 여유가 생길 때마다 머신러닝 등 고급 기능 또는 반복 입력 최소화 기능 추가
- 자동화가 불가능한 부분은 사용자 수동 입력으로 보완하는 **반자동 시스템**으로 초기 출발

### 2.2. 주요 개발 단계
```
자료 수집 → 데이터화 → 분류 → 엑셀 내역서 작성 → 원가계산서 생성 → 사용자 입력 보완
```

## 3. 시스템 구성 및 주요 기능

### 3.1. 입력 데이터 및 자료
- 건설공사 표준품셈 (PDF 또는 HWP)
- 노임단가표 (PDF)
- 조달청 제비율표 (PDF)
- 사용자 입력 자료 (자재 단가, 공정 정보, 수량 등)

### 3.2. 주요 기능 목록

| 기능 항목 | 설명 |
|-----------|------|
| 📥 PDF 데이터 수집 | 표준품셈 / 노임단가 / 제비율표 PDF 다운로드 및 저장 |
| 🧠 데이터 구조화 | PDF 내용 → JSON/CSV/DB 형태로 가공 및 분류 |
| 🧾 엑셀 내역서 자동 작성 | 가공된 데이터를 기존 엑셀 내역서 양식에 맞춰 자동 작성 |
| 🔁 노임단가 최신화 | 전기/당기 노임 비교 및 자동 대체 |
| ⚙ 제비율 자동 적용 | 조달청 제비율 데이터 기반 원가 계산서 최신화 |
| 🧮 수량산출 자동화 | 사용자가 UI로 수량 입력 → 수량산출서 및 내역서 자동 연결 |
| 🧍 사용자 입력 관리 | 자재단가, 공정내용, 공사 정보 등의 수동 입력 인터페이스 |
| 📄 서식 템플릿 유지 | 기존 엑셀 서식 틀 유지 및 작성 위치 자동 반영 |

## 4. 개발 단계 및 작업 순서

### 4.1. 1단계: 데이터 수집 및 정제
- 표준품셈 / 노임단가 / 제비율표 PDF 수집
- PDF → 텍스트 추출 → 구조화(카테고리, 단위, 금액 등)
- PDF가 복잡할 경우 OCR + 룩업 테이블 활용

### 4.2. 2단계: 데이터 저장 및 관리
- JSON or DB(PostgreSQL / Supabase)로 관리
- 연도별 버전 관리 (예: `표준품셈_2025`, `노임단가_Q2_2025`)

### 4.3. 3단계: 엑셀 자동작성 프로세스
- 기존 엑셀 템플릿 불러오기
- 지정 셀에 데이터 자동 삽입
- 수식 및 참조 자동 구성

### 4.4. 4단계: UI 및 사용자 입력 처리
- React 기반 간단한 입력 UI
- 자재 단가 / 수량 / 공정 정보 입력 → 엑셀 자동 반영

### 4.5. 5단계: 원가계산서 자동화
- 순공사비 산출 후 구성비 계산
- 조달청 제비율 기준 반영

### 4.6. 6단계: 반자동 요소 처리
- 자동화 어려운 항목은 수동 입력으로 처리 (예: 자재 가격)
- 유료 API가 필요한 경우, 별도 검토하여 사용 여부 결정

## 5. 사용자 입력 항목 정리

| 항목 | 비고 |
|------|------|
| 📌 자재 단가 | 유동적 가격. 사용자가 직접 조사하여 입력 or API 활용 가능성 |
| 📌 공정 내용 | 해당 공사에서 필요한 공정 명세 |
| 📌 공정 수량 | 각 공정별 물량 및 수량 |
| 📌 공사 정보 | 발주자, 공사명, 위치 등 기본정보 |

## 6. 개발 우선순위 및 로드맵

### 6.1. 1차 목표 (MVP 완성)
- PDF → 데이터화 → 엑셀 자동 삽입 기능 완성
- 기본 UI 구축 (수량 입력, 자재단가 입력)
- 노임단가 및 제비율 최신화 로직 구현

### 6.2. 2차 목표 (기능 확장)
- 수량산출서 자동 연결
- 공정 분류 및 자동 적용 로직
- 단가 추세 시각화 / API 연결 기능

### 6.3. 3차 목표 (고도화)
- 머신러닝 기반 공정 추천
- 공사 종류에 따른 템플릿 자동 제안
- 자동 테스팅 및 문서화

## 7. 기술 스택 제안

| 구성 요소 | 기술 |
|-----------|------|
| Backend | FastAPI (Python) |
| Frontend | React + TypeScript |
| DB | PostgreSQL (개발용), Supabase (프로덕션) |
| 파일 처리 | openpyxl, pandas, PyMuPDF / pdfplumber |
| 배포 | Tauri 또는 Electron (데스크탑 앱 형태) |
| 인증 | JWT + RBAC (확장 고려) |

## 8. 최종 목표

- 반복업무 제거 + 최신화된 정보 반영
- 완전 자동화된 설계 내역서 및 원가계산서 시스템 구축
- 수기 작업 없이 클릭만으로 공사 문서가 생성되는 구조 완성
